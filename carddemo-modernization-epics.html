Description

As a migration engineer, I want to create a PostgreSQL schema that maps all VSAM KSDS file layouts to relational tables so that the modernized services have a reliable data store.

Acceptance Criteria

  • All VSAM KSDS files (CUSTDATA, ACCTDATA, CARDDATA, CARDXREF, TRANSACT, TRANTYPE, TRANCATG, DISCGRP, TCATBALF, USRSEC) have corresponding PostgreSQL tables

  • Foreign key relationships between tables are defined where applicable
